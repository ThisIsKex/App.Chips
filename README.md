# CHIPS

Collaborative Handling of Individual Payments and Splitting

## Project Setup

```sh
npm install
amplify push
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```
